# Demo vault

A small sample of what an obsidian-wiki vault looks like after a few weeks of use: 18 pages on building reliable LLM agents, written in the framework's page format with provenance markers, confidence and lifecycle fields, and dense links.

It's sample content, not a real knowledge base. Nothing here is kept up to date.

**Open it:** in Obsidian, choose *Open folder as vault* and pick this folder. Then open the graph view (Cmd/Ctrl+P → "Open graph view"); nodes are colored by folder.

**Try the skills on it:** point your agent at this folder (for example `/wiki-query @demo what's the difference between RAG and a compiled wiki?` after `/wiki-switch`, or set `OBSIDIAN_VAULT_PATH` to this folder) and run `/wiki-query`, `/wiki-lint` or `/wiki-status`.

Start with [[index]] or [[synthesis/rag-vs-compiled-wiki]].
